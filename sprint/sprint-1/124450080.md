# Laporan Tugas Sprint 1

Laporan ini merangkum dua tugas Sprint 1: menyiapkan penyimpanan Silver pertama dan merangkum masalah data untuk bahan demo serta draf laporan tim. Rincian dan angka di bawah disusun dari draf yang sudah ada di [laporan tim](../../reports/tim.md); tautan keluaran disertakan agar hasilnya dapat ditelusuri.

## Tugas 1 — Persiapan tahap 5: rancangan dan pemuatan Silver

### Tujuan
Merancang tabel SQL untuk lapisan Silver dengan kunci primer dan tipe kolom yang jelas, mencoba memuat Silver pertama, serta mencatat alasan pemilihan basis data dan perbandingannya dengan dokumen JSON mentah.

### Hasil
- Basis data yang dipilih: **SQLite**, untuk pemakaian dan validasi lokal tanpa perlu menjalankan server.
- DDL dan skrip pemuat: [src/silver/sqlite.py](../../src/silver/sqlite.py).
- Silver pertama berhasil dimuat ke SQLite dengan **18.187 baris**.
- Pemeriksaan skema mencatat **15 seri** dan **39 wilayah**. Metrik validasi mencatat **12 dari 12 aturan lolos** dan **11 kolom terdokumentasi**.

### Alasan pilihan dan perbandingan
SQLite sesuai untuk tahap ini karena dapat dijalankan secara lokal tanpa server dan mendukung pemeriksaan data Silver secara langsung. Kolom bertipe dan kunci yang ditetapkan pada tabel SQL membantu pencarian, validasi, serta penggunaan data terstruktur. JSON mentah tetap dipertahankan sebagai sumber asli dan lebih fleksibel untuk menyimpan respons apa adanya, tetapi kurang praktis untuk kueri analitis terstruktur dibandingkan tabel SQL.

Rincian keputusan penyimpanan ada di [dokumen penyimpanan tahap 5](../../docs/tahap-5-penyimpanan.md). Ringkasan validasi dapat dilihat di [metrik validasi](../../results/124450063/metrics.json).
